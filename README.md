# SpeedyInterview

Interview practice web app built with React, Vite, and TypeScript.

**Live:** [speedyinterview.vercel.app](https://speedyinterview.vercel.app)

## Overview

SpeedyInterview is a front-end application for practicing interview-style workflows. It uses Vite for the build toolchain and a component-driven React UI (including shadcn-style setup).

## Stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Structure

```
src/           # App source, components, pages
public/        # Static assets
vite.config.ts
```

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Deploy

Configured for Vercel (`vercel.json`).
